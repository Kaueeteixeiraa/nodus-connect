# Nodus Connect

Suporte remoto para Windows, destinado exclusivamente a acessos autorizados.

## Download oficial

- [Site oficial](https://nodus-connect-download.vercel.app)
- [Versoes oficiais](https://github.com/Kaueeteixeiraa/nodus-connect/releases)

## Uso responsavel

Utilize somente em computadores proprios ou com autorizacao do responsavel. Acesso sem consentimento, coleta indevida de dados e qualquer uso ilegal sao proibidos.

## Privacidade

Nao publique credenciais, IDs de dispositivos, dados pessoais ou logs de sessoes em issues e comentarios publicos.
